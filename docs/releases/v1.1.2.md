# AULA Studio 1.1.2

## Changes

- Filters macOS receiver choices by the actual 32-byte output report and requests Input Monitoring access when macOS requires it.
- Matches the macOS title bar background to the selected light or dark app theme.
- Explicitly bundles the Windows ICO and macOS ICNS application icons.
- Documents the unsigned-app quarantine command and Input Monitoring setup.

## Compatibility

Apple Silicon macOS receiver detection and battery access were confirmed on an F75 Max. Windows x64 and Apple Silicon macOS packages are provided. The application remains unsigned and macOS notarization is not configured.
