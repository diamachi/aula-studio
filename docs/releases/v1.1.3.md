# AULA Studio v1.1.3

- Adds a Linux x64 AppImage built on Ubuntu 22.04.
- Includes a udev rule for access to the F75 Max wireless receiver and wired display endpoints without running the app as root.
- Extends GitHub Actions to build and publish the Linux package with the Windows and Apple Silicon macOS releases.

Linux AppImages require WebKitGTK 4.1 and FUSE 2 for mounting. Linux HID access and keyboard behavior have not yet been tested on physical hardware. Install the included udev rule before connecting the F75 Max.

Software checks and package builds run in GitHub Actions on Windows x64, Apple Silicon macOS and Linux x64. Lighting, per-key colors, battery and image/GIF playback have been confirmed on Windows hardware; receiver detection and battery access have been confirmed on Apple Silicon macOS. Linux physical hardware behavior remains unverified.

Packages are unsigned. macOS is not notarized. GIF display uploads require wired USB.
