Restores dependency versions corrupted during the v1.1.0 version bump. A fresh install with an empty cache now succeeds. Adds a scoped version-update script, stricter unused-code checks, Rust dependency caching, shared release-profile compilation for tests/builds, and avoids a duplicate frontend build. Removes unused mobile icons and obsolete 3D preview styling.

- Locally bundled serif headings with italic accents; offline on Windows and Mac.

- Refreshed screenshots, including light/dark main windows side by side.

15 Rust tests and production-DOM UI checks pass. Lighting and display playback were confirmed on a Windows F75 Max. Physical sleep timing/companion behavior, native title-bar appearance and macOS hardware operation still need verification. GIF uploads require wired USB.
